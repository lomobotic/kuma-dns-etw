Назначение скрипта

Скрипт предназначен для восстановления корректной работы ETW-сессии DNS Analytics на серверах Microsoft DNS, используемой для передачи событий в SIEM.

Необходимость применения скрипта возникает в случаях, когда параметры ETW-сессии самопроизвольно или в результате изменений конфигурации переключаются из режима «Реального времени» (Real-Time) в режим «Реального времени + запись в файл» (Real-Time + File Logging). В таком состоянии события начинают сохраняться в файл журнала (.etl), что приводит к постоянному росту его размера и может вызвать заполнение системного диска C:.

Скрипт полностью пересоздает ETW-сессию и возвращает ее в режим работы только в реальном времени без сохранения событий на диск.

Выполняемые действия
1. Остановка и удаление существующей ETW-сессии
PowerShell
1
logman stop etwDNS-Analytics -ets
2
logman delete etwDNS-Analytics

На данном этапе выполняется:

остановка действующей ETW-сессии DNS Analytics;
удаление существующей конфигурации сессии;
очистка возможных некорректных параметров, которые могли привести к записи событий в файл.
2. Удаление ранее созданного ETL-файла
PowerShell
1
Remove-Item "C:\Windows\System32\LogFiles\WMI\etwDNS-Analytics.etl" -Force -ErrorAction SilentlyContinue

Удаляется файл трассировки ETW, если он был создан ранее.

Цель операции:

освободить место на системном диске;
исключить дальнейшее использование устаревшего файла трассировки;
предотвратить накопление событий на диске после восстановления настроек.

3
-rt `
4

-ets

Создается новая ETW-сессия со следующими параметрами:

Провайдер: Microsoft-Windows-DNSServer
Уровень и маска событий: сбор всех доступных DNS Analytics событий.
Параметр -rt: включает режим работы в реальном времени без обязательной записи в файл.
Размер буфера (-bs 64): 64 КБ.
Минимальное количество буферов (64)
Максимальное количество буферов (256)

Указанные настройки обеспечивают стабильную передачу событий в систему мониторинга и снижают вероятность потери событий при высокой нагрузке на DNS-сервер.

Назначение основных параметров:

LogFileMode = 0x100
 Включает режим реального времени (Real-Time Mode) без необходимости записи событий в ETL-файл.

BufferSize = 64
 Размер каждого буфера ETW в килобайтах.

MinimumBuffers / MaximumBuffers
 Определяют диапазон количества выделяемых буферов для обработки потока событий.

ClockType = 1
 Использование системного времени для формирования временных меток событий.

FlushTimer = 1
 Принудительная выгрузка буферов каждые 1 секунду, что уменьшает задержку доставки событий в SIEM.

5. Запуск ETW-сессии
PowerShell
1
logman start etwDNS-Analytics -ets

После создания и настройки выполняется запуск ETW-сессии DNS Analytics.

В результате события DNS начинают передаваться потребителям ETW (в том числе агенту сбора логов SIEM) в режиме реального времени.

Результат выполнения

После выполнения скрипта:

восстанавливается работоспособность сбора DNS Analytics событий;
отключается запись событий в файл ETL;
удаляется ранее накопленный файл трассировки;
предотвращается неконтролируемый рост занимаемого места на диске C:;
обеспечивается корректная передача DNS-событий в SIEM в режиме реального времени.
